# Screenshot Directory

This directory stores the official screenshots and visual demos for ApplyTrack's documentation and `README.md`.

## Recommended Screenshots to Place Here:

### 1. Web Companion (Desktop & Responsive)
- **`web-dashboard.png`**: The main applications table / cards dashboard with search and active status filters.
- **`web-analytics.png`**: The career insights page with platform performance, response rates, and resume effectiveness.
- **`web-detail.png`**: Application detail view showing document preview, timeline, and company notes.

### 2. Android Client (Native Jetpack Compose)
- **`android-dashboard.png`**: The mobile dashboard with Material 3 styling and quick action buttons.
- **`android-detail.png`**: An application screen displaying status history and PDF/document attachment chips.
- **`android-analytics.png`**: The mobile metrics and breakdown charts.

*Tip: PNG or WebP format with clean mockups (or clean screen captures) works best.*
