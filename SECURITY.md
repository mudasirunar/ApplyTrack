# Security Policy

## Supported Versions

We release patches and security updates for the current active development branch:

| Version / Client | Supported |
| ---------------- | :-------: |
| WebApp (main)    |    ✅     |
| AndroidApp (main)|    ✅     |
| Older releases   |    ❌     |

---

## Reporting a Vulnerability

The ApplyTrack team takes the security and privacy of its users very seriously.

If you believe you have found a security vulnerability in ApplyTrack (such as an authentication bypass, data leakage between users in Firestore, or insecure storage access), **please do NOT report it via a public GitHub issue.**

### How to Report Privately

1. **Email:** Send a detailed report directly to the maintainer at **unarmudasir@gmail.com**.
2. **Include Details:**
   - A clear description of the vulnerability.
   - Exact steps or a Proof-of-Concept (PoC) to reproduce the issue.
   - Affected client(s) (Android, Web, or both).
   - Any suggested mitigations or patches if you have one.

### Our Commitment

- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a timeline for assessing and releasing a fix.
- We will coordinate with you on responsible public disclosure once a patch is deployed.
- We will gladly credit you in our release notes for responsible disclosure (unless you prefer to remain anonymous).
